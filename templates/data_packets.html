Data Packets

Data packets are a unit of data packaged as a single unit that travels from on device to another along a network path like the internet.
Data packets enable the transmission of information by breaking raw data into smaller, more manageable pieces that reassemble into readable data at the destination.
Data packets are used in Internet Protocol (IP) transmissions.
Data packets have 3 parts, a header, payload and trailer.

Parts of a data packet
Header Payload Trailer
Details Contains information including source IP address, port-numbers, destination and its sequence in the data Contains the actual data being transferred Informs the destination that it has reached the end of its travel as well as end/error checking

Switching

An important element of data packets is switching, a phrase used to describe the method of routing the data packets from the source to the destination. The Internet and most modern data networks make use of packet switching as opposed to circuit switching.

Packet switching vs Circuit switching
Packet switching Circuit switching
Details Data packets travel independently from each other and can take different network paths to the destination Data packets follows the same path as contiguous data flow
Examples Most modern networks, Internet, emails Voice communications, traditional telephone networks
Advantages Efficient and flexible transmission of data and very effective at handling large scale loads A dedicated path is open for the data, allowing for low latency, predictable performance and consistent bandwidth
Disadvantages Limited in scalability and reliance on a dedicated open path for data transfer Packets can get congested and experience delays, performance is not guaranteed and is complex implementation-wise
