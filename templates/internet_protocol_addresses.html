Internet Protocol Address

The IP (Internet Protocol) is a set of rules that allows computers and other devices to communicate over the Internet. It ensures that information transfer between computers reaches the correct destination by using a unique set of numbers IP. The IP is responsible for delivering packets of data from the source to its destination based on IP address.
Every device connected to an Internet network is assigned an IP address which acts as a "home address" that allows other devices to locate and send messages to it by providing the route.
IP works with the Internet Control Message Protocol (ICMP) to send error messages and other operational messages which informs the sender about errors in packet delivery.
IP does not establish a direct connection to the destination before sending the data, making use of data packet's nature of independent travel to make a connectionless protocol that allows for efficient and flexible data transfer.
