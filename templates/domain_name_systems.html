Domain Name Systems

DNS (Domain Name Systems) that facilitates the translation of human-readable domain name into IP addresses, enabling computer to communicate over the internet. DNS connects a domain name to its corresponding IP address, allowing browsers and devices to locate and communicate with servers on the Internet.

Process

  1. User Input: The user enters a domain name into the browser
  2. Local Cache Check The browser or OS (operating system) checks its cache for a stored IP address corresponding to the domain name
  3. DNS Resolver Query: If not, the request is sent to a DNS resolver
  4. Root Server Query: The resolver queries a root server which directs to the correct TLD (top-level-domain) server
  5. TLD Server Response: The TLD server directs the resolver to the domain's authoritative server
  6. Authoritative Server Response: The authoritative server returns the actual IP address
  7. Final Response: The resolver sends the IP address back to the user, and the browser connects to the server. The IP is also cached locally to access the website faster in the future.
